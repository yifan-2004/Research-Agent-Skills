# 相机坐标与框约定检查表

可视化前记录：

- 相机坐标轴方向、左右手系、单位；相机坐标与 LiDAR/world 坐标不能混用。
- 中心位置是几何中心还是底面中心。KITTI 标签常见的相机框位置是底面中心，dimensions 通常为 h,w,l，rotation_y 绕相机 y 轴；必须对照当前导出器实际代码确认。
- KITTI 的 alpha 是观察角，不能直接替代 rotation_y。框尺寸顺序要显式映射。
- 标定矩阵是否包含 rectification、外参或 baseline。若位置已经是 rectified camera coordinates，不能重复做变换。
- 图像是否已去畸变；投影应使用对应标定。原始畸变图需要其相机模型。
- 预测的 2D 框与 3D 框是否同一 image_id，同一分辨率，以及 score 是否已过滤。

## 投影核验

使用导出器声明的框约定建立 8 个角，对应位置与朝向变换到相机坐标，再投影到齐次像素坐标。透视除法前检查投影分母和相机深度。对 near plane 进行裁剪；不要通过取绝对值或夹紧 z 将相机后方框拉到画面上。

对一张有标定和已知几何的样本核对：框底部是否落在合理地面，轴向是否一致，远处框是否缩小，正前方位置是否落到合理像素。几何不自洽时输出诊断，不把框画出来就叫验证成功。

只有图片没有标定、或只有 2D bbox 时，可以做有明确标注的 2D overlay，不能推断真实 3D 结果。
